# 独立生成器验证记录

2026-10-12，版本 0.1.0。

- 固定模板源为 templates/steam-ppt-v1.json，打包不再从 work 中读取人工月报。
- 独立包只含生成器、适配器、渲染器、固定模板、说明和配置示例；没有登录凭据或本机固定路径。
- 使用 8 月 schema 2.0 冻结包，生成 5 页、84 对象，数据绑定协议有效，边界检查无问题。
- 最新包复制到含空格的新目录，从该目录执行。静态 HTML 与原位置生成的文件完全一致，不读取共享项目或其他项目目录。
- 输出目录存在时退出 1，未覆盖人工稿；数据月份与参数不同退出 1。
- 历史定级率和历史总评测数不能从旧项目隐式继承。在线入口读取前两个月；离线入口 --history 明确提供完整数据包数组。不提供时为空。
- 在线自动取数分支与 --history 分支本轮只完成实现检查，尚未在其他电脑运行；已验收的是已有数据包离线生成与目录迁移。
- 该包尚不含 Silex 安装程序、数据 skill 和 Python 环境。其他电脑完成这些安装配置后才能从月份直接取数并打开编辑器。
- 金榜长名称排版、历史指标完整性、全离线图片资产及 AI 自动连接仍待完善。
